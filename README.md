# Blockshot — 2D Minecraft-style Shooter

Simple browser game: 2-D blocky characters, grassy Minecraft-ish tiles and multiple levels.


How to run

Open `index.html` in a browser (double-click) or serve via a static server:

```bash
python3 -m http.server 8000
# then open http://localhost:8000
```

Controls
- Move: `WASD` or arrow keys (or joystick on mobile)
- Aim: mouse (or drag to aim on touch)
- Shoot: click or `Space` (or tap the `Shoot` button on mobile)

Features
- Blocky 2-D characters and Minecraft-like grassy tiles
- Multiple levels with escalating enemy counts
- Particle effects on enemy death
- Simple synthesized sounds for shooting and hits
- Level selector and persistent high score (localStorage)
